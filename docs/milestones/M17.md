# M17: community pack authoring + CI (tentacle-store without billing)

**Exit:** community packs have a **documented authoring path**, **CI that lints/validates** packs in `d4rk-pri0r/krellbot-community-packs`, and Labs workstation hooks to **browse/install community entries** without inventing a paid store or billing. Catalogue honesty preserved (signed paid catalogue remains M5). Unfinished M0–M13 owner gates stay in those files — reference only. Agents keep `PAPER_ONLY_RELEASE` True. Do not invent a Learn view. Do not flip `PAPER_ONLY_RELEASE`. Do not place real orders.

**Why this order:** Octobot tentacle-store gap without billing: `community.py` already fetches a allow-listed GitHub index, but install is CLI-thin and authoring/CI live outside Labs. M5 covered signed free+paid catalogue. This milestone makes **community** a trustworthy extension lane: author → CI → index → in-app install.

Rules for every task are in `AGENTS.md`. Agents skip `[owner]` tasks. Agents pick the lowest-numbered unchecked engineering task that has no open PR and does not depend on an unmerged task.

**Parallelism:** M17.1 ∥ M17.2; M17.3 after M17.1 (community repo — often `[owner]` or named external PR); M17.4 after M17.2; M17.5 after M17.3+M17.4; M17.6 after M17.5. Keep Labs tasks precise; community-repo work is a named dependency / owner note when agents lack write access.

  - Deps: none
  - Accept: `rg -n 'krellbot-community-packs|community pack' docs/` shows authoring + index rules; a doc-link or checklist named in the PR is complete enough to author without reading `community.py` source

- [ ] **M17.2 Labs community list/install API (web).** Authenticated loopback API lists installed community packs and installs from the allow-listed index via injectable Transport (extend `community.py` seams). CSRF/session/origin/host preserved. No CLI-only user feature addition.
  - Scope: `src/krellbot/community.py`, `api/app.py`, tests with fake transport
  - Deps: none (module exists)
  - Accept: `KRELLBOT_HOME=$(mktemp -d) uv run --no-sync pytest -q tests/test_community_packs_api.py` (or the behavior-named test in the PR) covers list + install + foreign URL refusal with fakes
