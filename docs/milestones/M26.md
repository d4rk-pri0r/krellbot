# M26: Full-screen Krell first-run wizard (V1 UX)

**Phase:** V1 front-door UX (builds on M24 IA; supersedes M25 coach
overlay composition without rewriting M19–M23 gates or M24 nav / More).

**Exit / gate:** a non-trader on a fresh paper-only install can complete
**full-screen Krell-led paper setup** (welcome → pick free strategy →
Start paper run → honest status → win) with almost no text, big friendly
buttons, and **zero** workstation / cockpit chrome until the wizard is
done or skipped. Girlfriend test: if she cannot finish alone, it is not
simple enough. Power features remain reachable via **More** / **Advanced**
after complete or skip. No Beginner/Power toggle. Agents keep
`PAPER_ONLY_RELEASE` True. Do not invent a Learn view. Do not flip
`PAPER_ONLY_RELEASE`. Do not place real orders. Do not tick M25.10.

**North star (store plan):** Project store
`docs/krell-first-run-wizard-plan.md` — owner rejected M25 ship-feel as
still overcomplicated (2026-11-18 / 2026-11-19):

1. Full-screen wizard (max ~4–5 steps); Krell mascot walks the user.
2. Per step: one Krell visual, ≤1 short sentence, one primary big CTA
   (secondary text link only if needed).
3. Hard rule: `WorkstationShell` chrome / `AppHome` cockpit modules stay
   **unmounted** until wizard complete or skip.
4. Keep M25 paper-arm win; kill hotspot-over-cockpit + first-run
   checklist chrome.
5. Signal tokens only (`KRELL-SIGNAL-20261010`); stage mascot assets with
   provenance from krellbot.dev / krellbot-cloud — do not invent art.
6. This milestone file (M26) + light product-direction / getting-started
   note that V1 first-run is the full-screen Krell wizard.
7. Outsider / girlfriend-test script stays **[owner]** — not an agent
   checkbox body (M26.9 supersedes M25.10 qualitative bar).

**Why this order:** M24 shipped IA; M25 shipped do-first activation but
still painted a coach on top of a console. M26 replaces the pattern with
a mascot-led full-screen gate aimed at the same retention predictor:
paper strategy chosen → paper run started → honest status — then reveal
the real app.

Rules for every task are in `AGENTS.md`. Agents skip `[owner]` tasks.
Agents pick the lowest-numbered unchecked engineering task that has no
open PR and does not depend on an unmerged task. Prefer parallel PRs
when independent; serialize wizard shell → app gate → wire
(M26.3 → M26.4 → M26.5).

**Parallelism:** M26.1 first (this file); M26.2 ∥ after M26.1; M26.3 after
M26.1 (prefer after M26.2 if assets needed for chrome tests); M26.4 after
M26.3; M26.5 after M26.4; M26.6 after M26.4 (∥ M26.5 if no clash);
M26.7 after M26.5–M26.6; M26.8 last agent; M26.9 [owner] last.
