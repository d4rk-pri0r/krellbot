# M24: Beginner-default front door (V1 UX)

**Phase:** V1 front-door UX (cross-cuts P0–P4 surfaces; does not rewrite
M19–M23 gates).

**Exit / gate:** a newcomer on a fresh paper-only install can complete
**Workspace → free starter → paper-arm → Run status** without opening
Studio, Research, or Deploy; power features remain reachable via **More**
/ **Advanced**. No Beginner/Power toggle. Agents keep
`PAPER_ONLY_RELEASE` True. Do not invent a Learn view. Do not flip
`PAPER_ONLY_RELEASE`. Do not place real orders.

**North star (store plan):** Project store
`docs/beginner-default-ux-plan.md` (KRE-187) — locked owner decisions
2026-11-18:

1. Primary nav: Workspace, Run, Packs, Strategies. More: Research,
   Studio, Operations, Deploy. Kill-switch / pause easy from Run.
2. Chooser A: home-mounted starter chooser.
3. Default artifact: free local starter (offline J1); catalogue secondary.
4. UI label “Workstation” → “Run” (route id stays `workstation`).
5. Light newcomers emphasis in `docs/product-direction.md`.
6. This milestone file (M24).
7. No soft Studio tips after first arm (silence).
8. ⌘K first action: Start free paper strategy.
9. Workstream G: Settings & trust cluster on home Advanced.
10. Outsider script stays **[owner]** — not an agent checkbox body.

**Why this order:** the engine already supports paper-first; the web
workstation still reads as an equal-weight cockpit. M24 rebalances
disclosure and copy so the default path feels inevitable while keeping
one binary and one open experience.

Rules for every task are in `AGENTS.md`. Agents skip `[owner]` tasks.
Agents pick the lowest-numbered unchecked engineering task that has no
open PR and does not depend on an unmerged task. Prefer parallel PRs
when independent; serialize AppHome → chooser (M24.2 → M24.3).

**Parallelism:** M24.1 ∥ M24.2 after this file merges; M24.3 after M24.2;
M24.4 after M24.2 (∥ M24.3 OK); M24.5 ∥ M24.1–M24.4 once labels land;
M24.6 after M24.2 (palette CTA can land with chooser); M24.7 after
M24.1–M24.6; M24.8 after M24.7; M24.9 [owner] last.
