# M22 / P3: agent-ready

**Phase:** P3 — Agent-ready.

**Exit / gate:** an external agent completes **validate → backtest →
paper-arm** through MCP (or the chosen client skill), and a **user
policy file** refusal (e.g. deny live / deny keys) is **journaled**.
MCP never live-arms and never reads or transmits exchange keys.
Unfinished M0–M21 work stays in those files. Fake transports only in
CI. Do not invent a Learn view.

**Why this order:** exchanges ship free AI agent tooling; Krellbot’s
edge is local policy-bound automation with receipts — not cloud keys.
Builds on existing pack validate, research, and paper arm APIs.

Rules for every task are in `AGENTS.md`. Agents skip `[owner]` tasks.
**Do not start M22 engineering until the owner merges the roadmap PR
and P2 gate is accepted (or owner explicitly waives sequencing).**

**Parallelism:** M22.1 first (MCP surface contract); M22.2 ∥ M22.3
after M22.1; M22.4 after M22.2; M22.5 after M22.1; M22.6 [owner] /
spike can parallel M22.5; M22.7 [owner] gate last.

## Epic M22-A — MCP tools (safe)

- [x] **M22.1 MCP read / draft / validate / backtest / paper-arm.**
  Expose local MCP tools for those verbs only against the loopback
  app/domain; CI uses fakes; tools refuse live arm and any key read
  with typed errors.

    tests with fake transports
  - Deps: existing validate/research/paper APIs
  - Note: **risk-path** if wired through `run/` / `venues/` /
    `execution/` → owner merge; prefer application-layer facades

- [x] **M22.2 User policy file.** Operator-owned policy file under
  `$KRELLBOT_HOME` (e.g. allow paper-arm, deny live, deny key export);
  MCP and workstation honor it; changes are audited.
  - Scope: policy schema + loader + enforce seams
  - Deps: M22.1
  - Accept: `KRELLBOT_HOME=$(mktemp -d) uv run --no-sync pytest -q tests/test_user_policy_file_enforcement.py` (or the behavior-named test in the PR)

- [x] **M22.3 Policy refuse journaled.** When policy denies an agent
