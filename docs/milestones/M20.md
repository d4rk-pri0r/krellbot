# M20 / P1: live from the web (Kraken)

**Phase:** P1 — Live from web.

**Exit / gate:** an outsider places a **minimum-size live Kraken order
using only the web workstation** (no CLI live user path), with trade-only
keys, typed human confirmation, guardrails, and a live journal that
reconciles. Unfinished M0–M19 owner gates stay in those files —
reference only. Agents keep `PAPER_ONLY_RELEASE` True until the final
owner flip. Do not invent a Learn view. Do not place real orders
(agents). Prefer fake transports in CI.

**Why this order:** M1/M3/M10 already built web live authorization,
keys onboarding, and gated live arm behind `PAPER_ONLY_RELEASE`. This
phase finishes outsider-ready live on **Kraken only**, then the owner
flips the release flag. Coinbase/Binance live wait; paper breadth in
M14 may continue separately without expanding live venues before P4.

Rules for every task are in `AGENTS.md`. Agents skip `[owner]` tasks.
**Do not start M20 engineering until the owner merges the roadmap PR
and M19’s gate is accepted (or owner explicitly waives sequencing).**

**Parallelism:** M20.1 → M20.2 → M20.3; M20.4 ∥ M20.5 after M20.1;
M20.6 [owner] last (`PAPER_ONLY_RELEASE`). Risk-path slices need owner
merge.
