# M21 / P2: paid 1.0

**Phase:** P2 — Paid 1.0.

**Exit / gate:** **10 paying customers** with **day-30 retention**
evidence on one launch pack family, with live checkout, refund path,
funnel telemetry (opt-in), and disclosures that packs are not
personalized advice. Unfinished M0–M20 owner gates stay in those files.
Agents never process real charges in CI — fake processors only. Do not
invent a Learn view. Do not flip `PAPER_ONLY_RELEASE` here (P1 owns that).

**Why this order:** M5 already ships signed catalogue list, browse,
install, and activation redeem UI. Paid 1.0 closes **live checkout**,
honesty for **one** launch pack family, refunds, and measured funnel —
not a second product line.

Rules for every task are in `AGENTS.md`. Agents skip `[owner]` tasks.
**Do not start M21 engineering until the owner merges the roadmap PR
and P1 gate is accepted (or owner explicitly waives sequencing).**

**Parallelism:** M21.1 first (checkout seam); M21.2 ∥ M21.3 after
M21.1; M21.4 after M21.1; M21.5 ∥ disclosures with M21.2; M21.6 [owner]
last.

## Epic M21-A — Checkout and pack honesty

- [ ] **M21.1 Live checkout seam (fake processor in CI).** Workstation
  or site checkout starts a paid entitlement for a catalogue SKU;
  success refreshes entitlements; failure leaves trading/export
  unblocked. Tests use a fake payment transport only — no real
  processor keys in repo.
  - Scope: activation/checkout API, packs UI, injectable transport
  - Deps: M5.1–M5.3 (done on main)
  - Note: if touching `license.py` → **risk-path** → owner merge
  - Accept: `KRELLBOT_HOME=$(mktemp -d) uv run --no-sync pytest -q tests/test_live_checkout_fake_processor.py && cd frontend && npm run test:unit -- --run` (or the behavior-named tests in the PR)

- [ ] **M21.2 One launch pack family — honesty.** Document and enforce
  copy for a single launch pack family (default proposal: **DCA mode
  pack family** unless owner picks another): no returns promises;
  fixture/backtest labeled; not personalized advice; signed catalogue
  entry matches installed bytes.
  - Scope: pack metadata/docs, Packs UI copy, catalogue fixture tests
  - Deps: M21.1; M15 mode packs as content candidates
  - Accept: `KRELLBOT_HOME=$(mktemp -d) uv run --no-sync pytest -q tests/test_launch_pack_family_honesty.py && cd frontend && npm run test:unit -- --run` (or the behavior-named tests in the PR)
