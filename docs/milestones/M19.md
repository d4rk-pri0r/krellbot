# M19 / P0: evidence and trust

**Phase:** P0 — Evidence / trust.

**Exit / gate:** an outsider installs the current published cut on macOS
or Windows **without a Gatekeeper/SmartScreen first-run warning**, opens
the workstation, and **reproduces a pack** (validate + pinned research
or paper arm) with receipts that match docs. Unfinished M0–M18 owner
gates stay in those files — do not re-list them. Agents keep
`PAPER_ONLY_RELEASE` True. Do not invent a Learn view. Do not flip
`PAPER_ONLY_RELEASE`. Do not place real orders.

**Why this order:** install trust and reproducible evidence are the
front door before qualified live (P1) or paid 1.0 (P2). Overlaps
owner-held signing (M12.1) and README honesty — this phase sequences
the remaining trust surface without rewriting M14–M18.

Rules for every task are in `AGENTS.md`. Agents skip `[owner]` tasks.
Agents pick the lowest-numbered unchecked engineering task that has no
open PR and does not depend on an unmerged task. **Do not start M19
engineering until the owner merges the roadmap PR that added this
file.**

**Parallelism:** M19.1 [owner] first (signing cut); M19.2 ∥ M19.3 ∥
M19.4 after docs/signing posture is clear; M19.5 after M19.1 (README /
live.md align can draft earlier but must not claim signed GA early);
M19.6 [owner] gate last.
