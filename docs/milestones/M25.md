# M25: First-run activation walkthrough (V1 UX)

**Phase:** V1 front-door UX (builds on M24 beginner-default IA; does not
rewrite M19–M23 gates or M24 nav / More decisions).

**Exit / gate:** a newcomer on a fresh paper-only install can complete
an **interactive paper-arm activation** (coach → starter cards → Start
paper run → honest Run status → brief win) without reading a lecture,
opening Studio, or hunting Advanced. Power features remain reachable via
**More** / **Advanced** after coach complete or skip. No Beginner/Power
toggle. Agents keep `PAPER_ONLY_RELEASE` True. Do not invent a Learn
view. Do not flip `PAPER_ONLY_RELEASE`. Do not place real orders.

**North star (store plan):** Project store
`docs/first-run-activation-plan.md` — owner rejected the M24 screenshot
demo as ship-ready (2026-11-18); adopt Moonb walkthrough patterns
(interactive hotspot coach, ≤3-item checklist, empty state → prompt):

1. Interactive FirstRunCoach (spotlight one control; skip after open;
   persist completed / skipped).
2. Wire coach steps: home CTA → consumer chooser → Run arm → status.
3. Activation checklist (3 items max; one pre-checked; tied to real
   state).
4. Consumer starter chooser (3 plain cards; kill JSON/seed/XXBT /
   NameEducational glue bugs).
5. Run first-session empty → single arm prompt; demote rehearsal /
   inspector until armed or skip.
6. Home first-viewport composition (brand + one CTA; hide Advanced stack
   until coach done/skip).
7. First-win celebrate then silence; density / e2e / journey pins.
8. Recapture ship-feel demo pack + notes.
9. This milestone file (M25) + short product-direction / getting-started
   note that V1 first-run aims at interactive paper-arm activation.
10. Outsider script stays **[owner]** — not an agent checkbox body
    (M25.10 supersedes M24.9 qualitative bar for coach path).

**Why this order:** M24 shipped the information architecture (nav More,
AppHome CTA, Chooser A, Run label). Screenshots still read as an
operator console with a reading list. M25 replaces the passive tour with
**do-first activation** aimed at the retention predictor: paper strategy
chosen → paper run started → honest status on Run, in ≤60–90 seconds of
guided doing.

Rules for every task are in `AGENTS.md`. Agents skip `[owner]` tasks.
Agents pick the lowest-numbered unchecked engineering task that has no
open PR and does not depend on an unmerged task. Prefer parallel PRs
when independent; serialize coach shell → wire (M25.2 → M25.3) and Run
empty → home composition (M25.6 → M25.7); checklist ∥ chooser after
M25.1 if no AppHome clash.

**Parallelism:** M25.1 first (this file); M25.2 → M25.3; M25.4 ∥ M25.5
after M25.1 (prefer serial if AppHome conflict); M25.6 after M25.3;
M25.7 after M25.3 (∥ M25.6 OK if no clash); M25.8 after M25.4–M25.7;
M25.9 last agent; M25.10 [owner] last.
