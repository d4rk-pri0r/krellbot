### J7. Export results and history
Anything I can see, I can export, and the file matches the screen.
- J7.1 I can export a backtest's results and its bar-by-bar trace, and the files match the screen: same numbers, same rows.
- J7.2 I can export paper status and history, and the file matches the paper journal.
- J7.3 An exported backtest carries what it takes to reproduce it: the strategy fingerprint, the data fingerprint, the window and the cost settings.
- J7.4 Export works offline and without an account, even when billing or the website is down.
- J7.5 If an export can't finish, the screen says so, and no partial file is offered as complete.
